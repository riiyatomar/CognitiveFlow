# Design Guidelines: AI Cognitive Aid for Early Dementia

## Design Approach
**Reference-Based Approach** - Drawing inspiration from healthcare and accessibility-focused applications like Headspace, Calm, and modern medical platforms. This project requires empathetic, trust-building design that prioritizes usability for users with cognitive challenges.

## Core Design Principles
- **Accessibility-First**: Large touch targets, high contrast, simple navigation
- **Calming & Trustworthy**: Reduce anxiety through gentle, professional aesthetics
- **Cognitive Load Reduction**: Minimal choices, clear hierarchy, predictable patterns

## Color Palette
**Primary Colors (Dark Mode):**
- Background: 220 15% 8% (deep navy-blue)
- Surface: 220 20% 12% (lighter navy)
- Primary: 200 85% 65% (soft blue)
- Text: 210 15% 95% (near white)

**Light Mode:**
- Background: 210 25% 98% (soft white)
- Surface: 210 20% 95% (light gray)
- Primary: 200 75% 45% (professional blue)
- Text: 220 15% 15% (dark gray)

**Accent Colors:**
- Success: 145 70% 50% (calming green)
- Warning: 25 85% 60% (warm orange)
- Gentle gradients from primary blue to soft teal (180 60% 70%)

## Typography
- **Primary**: Inter (Google Fonts) - excellent readability
- **Sizes**: Large base (18px), generous line height (1.6)
- **Hierarchy**: Clear size jumps (1.25x scale) for easy scanning

## Layout System
**Tailwind Spacing**: Use units of 4, 6, 8, 12 for consistent, generous spacing
- Large touch targets (min 44px)
- Generous whitespace between sections
- Maximum content width of 1200px for readability

## Component Library

### Navigation
- Large, labeled icons with text
- Breadcrumb navigation for context
- Prominent "Home" button always visible

### Forms & Interactions
- Large input fields with clear labels
- Single-column layouts to reduce confusion
- Progress indicators for multi-step processes
- Confirmation dialogs for important actions

### Cards & Content
- Rounded corners (8px) for friendliness
- Subtle shadows for depth
- Large, readable fonts throughout
- Icons paired with text labels

### Memory Assessment Tools
- Card-based memory games with large, clear imagery
- Voice recording interfaces with prominent record/stop buttons
- Calendar widgets with large date selections
- Medication reminders with clear visual cues

## Key Features Layout

### Hero Section
- Welcoming headline emphasizing support and assistance
- Large CTA button for "Start Assessment" or "Continue Journey"
- Calming background gradient (blue to teal)
- Professional imagery showing supportive technology

### Assessment Dashboard
- Clean grid layout with large assessment cards
- Progress tracking with encouraging language
- Recent activities section
- Emergency contact access

### Memory Exercises
- Game-like interfaces with large, colorful elements
- Clear instructions with audio support options
- Gentle animations for feedback (success/try again)

## Images
- **Hero Image**: Elderly person comfortably using tablet, warm lighting, expressing confidence
- **Feature Icons**: Large, friendly illustrations of brain health, memory exercises, family connections
- **Assessment Cards**: Cheerful, abstract imagery representing different cognitive activities
- **Background Elements**: Subtle, calming patterns or gradients, never busy or distracting

## Accessibility Features
- High contrast mode toggle
- Font size adjustment controls
- Voice navigation support indicators
- Screen reader optimized structure
- Keyboard navigation highlighting

This design balances professional healthcare credibility with warmth and accessibility, creating a trustworthy environment for users navigating cognitive challenges.
